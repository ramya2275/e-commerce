Key Kubernetes Capabilities

Production patterns configured in k8s/ manifests.

  • ✓
    Liveness & Readiness Probes:
    Every container exposes /health/live and /health/ready for automatic restart and traffic routing.
  • ✓
    Horizontal Pod Autoscaling (HPA):
    Configured in 06-hpa.yaml to autoscale pods between 2 and 5 replicas at 70% CPU load.
  • ✓
    Service Discovery via CoreDNS:
    Decoupled inter-service communication without hardcoded IP addresses.
  • ✓
    ConfigMaps & Environment Decoupling:
    Microservices configs externalized in 01-configmap.yaml.
